# 🛡️ Cybersecurity Foundations Portfolio

> **A hands-on cybersecurity portfolio exploring reconnaissance, phishing analysis, threat modelling, network security, Linux investigation, digital forensics, attack analysis, and risk-based vulnerability management.**

This repository contains **10 cybersecurity projects** completed as part of a 90-day cybersecurity learning journey.

The portfolio demonstrates a progression from understanding personal security and reconnaissance to investigating attacks, analysing systems, strengthening networks, and making **risk-based security decisions**.

---

## 👋 About This Portfolio

Before beginning this journey, I primarily viewed cybersecurity from an attacker's perspective — the stereotypical *"black screen with green text"* and breaking into systems.

Through these projects, I developed a broader understanding of cybersecurity as a discipline focused on **protecting people, systems, data, and businesses while managing risk**.

The projects emphasize practical investigation, analytical thinking, security controls, and decision-making rather than simply identifying technical vulnerabilities.

# 🧠 Security Mindset

One of the most important lessons from this portfolio is that **security is not about eliminating every possible risk**.

In a real organization, security decisions have to consider:

```text
             ┌──────────────────────┐
             │      BUSINESS        │
             │       GOALS          │
             └──────────┬───────────┘
                        │
                        ▼
             ┌──────────────────────┐
             │       RISKS          │
             │ Threats + Impact     │
             └──────────┬───────────┘
                        │
                        ▼
             ┌──────────────────────┐
             │    SECURITY          │
             │     CONTROLS         │
             └──────────┬───────────┘
                        │
                        ▼
             ┌──────────────────────┐
             │   ACCEPTABLE RISK    │
             └──────────────────────┘
```

The goal is to **reduce risk to an acceptable level** using the resources available while considering business requirements, operational constraints, and potential impact.

This shift from *"How do I stop everything?"* to *"How do I manage risk effectively?"* is one of the key ideas reflected throughout this portfolio.
